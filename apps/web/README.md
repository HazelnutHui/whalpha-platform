# Trading Intelligence Web

React frontend scaffold for Trading Intelligence Platform.

## Purpose

The current frontend verifies the React/Vite boundary and the Health API contract. It is not the Dashboard V1 implementation.

## Current Page

The app renders a local development status page showing:

- frontend readiness
- API health state
- data provider status
- market data status
- deployment status

## Local Setup

Use the repository-level instructions in [Local Development](../../docs/development/local-development.md).

## Current Non-Goals

- No market dashboard
- No heatmap or treemap implementation
- No real market data
- No login flow
- No production deployment configuration
