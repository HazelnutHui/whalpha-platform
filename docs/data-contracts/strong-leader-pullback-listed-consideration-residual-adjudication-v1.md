# Strong-Leader Pullback Listed-Consideration Residual Adjudication V1

## Purpose

`strong-leader-pullback-listed-consideration-residual-adjudication/1.0`
resolves only the three listed-stock consideration identities excluded by the
original 12-case adjudication. The original nine matches remain immutable.

## Inputs and binding

The network-disabled operation formally rereads and binds the original source
plan and source package, prior identity adjudication, three-case residual plan,
one-document residual source package, and common-share completion-consideration
adjudication.

Each decision retains the target and proposed consideration stable IDs, CIK,
original and residual plan fingerprints, original and replacement artifact
hashes where applicable, completion-disclosure identifiers and evidence hash,
expected ratio, evidence-gate booleans, bounded registration evidence, reasons,
resolution, and assignment.

## Evidence paths

- sequences 158 and 184 require the existing issuer registration to prove the
  transaction and both common-security classes, plus the target completion
  disclosure to prove the final ratio and both security terms;
- sequence 174 requires the replacement Fifth Third merger 424B3 to prove the
  transaction, both common-security classes, and final ratio, plus the Comerica
  completion disclosure as an independent cross-check; and
- all three require the frozen CIK-to-point-in-time stable common-security
  identifier chain.

Names and tickers remain locators. A missing, changed, or inconsistent element
produces `required_evidence_not_matched` and no assignment.

## Authority

The report may assign only the three evidence-scoped consideration stable IDs.
It calculates no terminal value, outcome, label, return, or metric and performs
no canonical data or Historical Coverage write, research admission, Candidate
write, publication, deployment, or scheduler change. The canonical JSON report
uses owner-only `0700/0400` custody.
