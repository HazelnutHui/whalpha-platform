# Strong-Leader Pullback Listed-Consideration Residual Terminal Evidence V1

## Purpose

`strong-leader-pullback-listed-consideration-residual-terminal-evidence/1.0`
adds daily gross reference values for the three residual identities without
rewriting the original nine-value report.

## Inputs and calculation

The network-disabled builder formally rereads and binds the original terminal-
evidence report, residual identity adjudication, common-share consideration,
trading cessation, normalized payoff terms, and only the required canonical
EOD/Identity sessions.

Each decision uses:

`gross reference value = guaranteed cash + listed ratio × unadjusted close`

The close is the assigned consideration security's unique valid USD latest-
revision close on the target's first absent exchange session. The report
retains the ratio and cash term fingerprints, exact session integrity and
Identity fingerprints, partition custody time, price source and revision,
quality status and flags, and the residual identity-decision fingerprint.

The report exposes 9 prior, 3 residual, and 12 cumulative reference values.
The original nine decisions remain unchanged.

## Authority

These are gross daily reference values, not execution prices, legal settlement
values, canonical outcomes, strategy labels, returns, metrics, or option
results. Source acceptance and partition creation times cannot become signal
features. The report writes no canonical data or Historical Coverage, admits
no research, and creates no Candidate, publication, deployment, or scheduler
state. Canonical JSON uses owner-only `0700/0400` custody.
