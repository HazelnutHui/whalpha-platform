# Strong-Leader Pullback SEC Case Coverage Census V1

## Purpose

`strong-leader-pullback-sec-case-coverage-census/1.0` joins the frozen 64-case
lifecycle sample to the complete Form 25, Form 15, and transaction candidate
packages by stable-ID locator. It measures where candidate evidence exists
before any field-value or security-identity adjudication.

It is not a lifecycle fact table, terminal-outcome table, research input, or
provider acceptance result.

## Inputs and binding

The network-disabled builder formally rereads:

- the 64 lifecycle cases in the source-acceptance sample;
- 64 Form 25 candidate documents;
- 66 Form 15 candidate documents; and
- 89 transaction-adjacent candidate documents.

All candidate packages must share the same plan, source-manifest, and content-
census identities. Their 219 documents must map exactly to the 64 frozen
lifecycle stable-ID locators, without missing or extra IDs.

## Case profile

Each stable-ID case records source locators, last observation, provider delist-
date candidate, document counts, repeated-family counts, Form 15 multi-file-
number counts, and transaction structure counts. Exactly one evidence profile
is assigned:

- structured 8-K transaction scope;
- notice-only with no transaction document;
- completion exhibit referenced but body missing; or
- no registered transaction-completion scope.

These profiles describe retained source structure, not the security outcome.

## Field coverage

For each of the eight registered lifecycle fields, the case retains exact
Form 25, Form 15, and transaction candidate-document counts. Candidate
presence means only that a prior extractor retained partial source evidence.
Absence means only absence from the retained primary documents.

Every complete result remains `unsupported` with reason
`candidate_semantics_and_security_identity_unadjudicated`. Therefore all 512
case/field cells remain unadjudicated. Matched, absent, ambiguous, conflicting,
and irrelevant field counts remain zero until a later typed review actually
establishes those states.

## Authority

The report is canonical JSON in owner-only `0700/0400` custody. Stable-security
assignments, transaction facts, lifecycle facts, terminal outcomes, strategy
outcomes, `/data`, Historical Coverage, research admission, Candidate writes,
publication, deployment, and scheduler counts remain zero.
