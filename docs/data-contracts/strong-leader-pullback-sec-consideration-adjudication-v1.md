# Strong-Leader Pullback SEC Consideration Adjudication V1

## Purpose

`strong-leader-pullback-sec-consideration-adjudication/1.0` preserves typed
ordinary/common-share consideration evidence for the 61 first-strategy cases
with matched SEC identity, transaction completion, and listing-termination
reason.

It does not normalize payoff amounts, adjudicate party relations or
tradability, calculate terminal returns, write canonical lifecycle facts, or
admit any case to research or Production.

## Input binding and scope

The network-disabled builder rereads and binds the immutable document plan,
source package, cover identity, transaction events, and termination reasons.
Raw-document hashes, stable `instrument_id` values, accessions, and all prior
decision fingerprints must agree.

Only the previously hashed introduction-plus-Item-2.01 transaction scope is
used. The primary evidence clause must describe all outstanding common shares
in a tender offer or the conversion of issued/outstanding ordinary/common
shares in a completed merger.

## Classification

The registered structures are `cash_only`, `stock_only`,
`fixed_cash_and_stock`, `cash_plus_contingent_value_right`,
`holder_election_cash_or_stock`, and
`holder_election_cash_or_cash_plus_unlisted_unit`.

Cash in lieu of fractional shares is a separate adjustment, not a primary cash
component. Options, restricted awards, preferred stock, debt, and financing do
not determine the classification.

## Authority boundary

The complete primary clause, normalized offsets, and digest retain exact source
evidence. Numeric consideration terms remain unnormalized. The report creates
no canonical lifecycle fact, terminal outcome, performance metric, or research
authority.

The canonical JSON report is stored in owner-only `0700/0400` custody and is
bound to code, source, prior evidence, and ruleset fingerprints.
