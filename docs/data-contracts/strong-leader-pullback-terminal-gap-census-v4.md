# Strong-Leader Pullback Terminal Gap Census V4

## Purpose

`strong-leader-pullback-terminal-gap-census/4.0` is an immutable,
outcome-blind extension of the corrected V3 terminal worklist. It binds four
daily references that are fully supported by retained source evidence and
canonical stable-ID EOD data.

The report records the exact upstream report hashes, SEC Submissions package,
same-session price evidence, case-level reference values, remaining state and
horizon impacts, implementation revision, and logical fingerprint.

## Boundaries

- RNAM, TERN, and PLYM require exact source-stated cessation timing.
- FL uses only the contractual fixed-cash default when no valid election
  exists. THR remains unresolved because its mixed default is prorated.
- A reference is not an execution price, realized election, terminal outcome,
  forward return, or performance result.
- Unresolved successor identity, election/proration, complex/contingent value,
  missing primary source, and cessation/EOD conflicts remain explicit.
- Network, `/data`, Historical Coverage, research, Candidate, publication,
  deployment, and scheduler changes are prohibited.
