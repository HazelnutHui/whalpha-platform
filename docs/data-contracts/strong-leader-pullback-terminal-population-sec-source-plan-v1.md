# Strong-Leader Pullback Terminal-Population SEC Source Plan V1

## Purpose

`strong-leader-pullback-terminal-population-sec-source-plan/1.0` freezes the
official SEC primary-document requests for cases added by the corrected EOD
terminal boundary. It is a zero-network plan, not source custody or a fact.

## Binding and selection

The report formally binds terminal-gap census V2, its stable-ID lifecycle
source/decision anchors, and the complete SEC Submissions package and payload
census. CIK, exchange, provider effective-date candidate, and selected stable
identity must agree across retained lifecycle occurrences.

Only direct lifecycle forms or structured lifecycle 8-K filings whose filing
date is on or after the stable ID's corrected last EOD presence are retained.
Each request preserves the accession, acceptance time, primary document,
source member, structured items, exact SEC URL, and relation to the corrected
EOD and provider-date boundaries.

## Request and custody boundary

The request envelope permits only HTTPS GETs to `www.sec.gov`, at no more than
two requests per second, with at most two retries and 64 MiB per response.
Those limits describe a later acquisition; this plan executes zero requests
and reads no User-Agent configuration.

The canonical JSON is created exclusively and atomically beneath an owner-only
`plan=*` directory, then formally reread. Exact replay is idempotent and a
different replay fails closed.

## Non-authority

Ticker never proves identity. Filing metadata and source locators do not prove
transaction completion, cessation, legal delisting, consideration, terminal
value, outcome, or return. The plan grants no `/data`, Historical Coverage,
research admission, Candidate, publication, deployment, or scheduler authority.
