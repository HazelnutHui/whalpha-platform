# Strong-Leader Pullback Terminal-Population Trading Cessation Adjudication V1

## Purpose

`strong-leader-pullback-terminal-population-trading-cessation-adjudication/1.0`
compares one exact source-stated SCS trading-stop boundary with formal
stable-ID EOD presence. It is not a legal delisting or terminal-outcome
contract.

## Input and decision

The report binds the corrected-population SEC core-adjudication SHA-256,
logical fingerprint, and source-case fingerprint. It selects one realized
before-open trading-stop sentence with one unambiguous date and requires that
date to equal the adjudicated transaction-completion date.

The canonical session index determines the expected prior EOD session and next
exchange session. Only the prior, expected-final, and next EOD partitions are
formally reread. Every retained observation includes partition and historical
Identity integrity fingerprints and presence keyed by stable `instrument_id`.

`matched` requires presence on the expected final EOD session and absence on
the next exchange session. Any mismatch is `conflicting`; missing or ambiguous
source timing is `unsupported`.

## Non-authority and custody

The source-stated stop boundary and last retained EOD observation do not prove
first tradability, legal delisting effectiveness, intraday execution, payoff,
terminal value, or a lifecycle fact. All terminal, performance, admission,
canonical-write, publication, deployment, and scheduler counters remain zero.

The canonical JSON is atomically written and formally reread beneath one
owner-only `adjudication=*` directory. Directories are `0700`, the report is
`0400`, and an exact replay is idempotent.
