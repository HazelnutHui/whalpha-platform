# ADR 0221: Scope Action and Lifecycle Gaps to the First Strategy

- Status: Accepted
- Date: 2026-09-13

## Context

The five-year Corporate Action Resolution Shadow accounts for 242,242 source
rows, but 112,943 typed rows remain unresolved. The residual-evidence census
proves that most of this global population concerns securities or dates that
need not be resolved before the first registered Strong-Leader Pullback
development question can be assessed. Continuing global resolution without a
strategy scope would spend time on funds, preferreds, OTC securities, and
events outside the declared path while leaving the actual development blockers
unnamed.

The first experiment already fixes a 287-session reconstructed Primary scope,
a 20-session feature lookback, next-session-open entry, and 1/3/5-session
underlying-stock price-return horizons. Its admission decision remains
rejected and outcome-blind. These fixed paths can therefore be used to measure
evidence intersection without calculating a trigger, return, metric, or
parameter result.

## Decision

Create one immutable, owner-only Strong-Leader Pullback evidence-blocker census
with the following boundaries:

1. Formally reread the exact development coverage report, rejected admission
   decision, all 287 reconstructed Membership partitions, the current
   Corporate Action Resolution Shadow, both inactive-lifecycle anchors, and
   the residual-evidence census. Validate the immutable unresolved-candidate
   output and bind it to the formally reread resolution shadow without
   repeating its complete 1,253-session Resolver scan.
2. Retain one action-exposure row for every exact resolved action or explicitly
   unassigned history-wide candidate relation that intersects at least one
   included Primary feature path or 1/3/5-session label window.
3. Treat the feature action window as sessions `t-19` through `t`; an event on
   `t-20` has no earlier pre-event bar inside the 21-session feature panel.
   Treat label-event windows as `t+1` through the selected horizon, preserving
   the next-open entry boundary.
4. Keep exact event-date stable-ID resolution distinct from an unassigned
   history-wide candidate. A unique candidate is not an assignment, and a
   multiple-candidate relation is not collapsed.
5. Retain one deduplicated lifecycle window for each inactive-source review
   candidate that was included at least once. Measure when the declared label
   window crosses the last canonical observation or the provider delisting-date
   candidate; do not promote either date to a terminal outcome.
6. Bind the full global unresolved denominator and explicitly state that rows
   with no history candidate are unscoped, not proven irrelevant. The census is
   a source-acquisition and semantic-priority diagnostic only.
7. Write only a new immutable three-file package outside `/data`, with
   owner-only modes, exclusive atomic completion, deterministic fingerprints,
   and a full output reread.
8. Keep strategy triggers, outcomes, metrics, parameter selection, cohort
   selection, stable-ID assignment, canonical writes, Historical Coverage,
   research admission, Candidate authority, publication, deployment,
   scheduler mutation, and external requests at zero or false.

## Consequences

The next data decision can be based on the first strategy's actual action and
lifecycle cases rather than the global unresolved count. Resolved actions can
move to explicit price-return and adjustment semantics; the small unresolved
intersection becomes a named cross-venue source sample; and lifecycle source
evaluation can focus on securities whose registered label windows cross known
terminal boundaries.

This census cannot admit development. Missing-event neutrality and canonical
lifecycle completeness remain global evidence requirements under ADR 0195,
and latest-vintage Membership remains research-only.

## Acceptance boundary

Tests must cover feature and every horizon boundary, resolved versus candidate
identity, multiple candidates, no-candidate accounting, lifecycle deduplication,
tamper rejection, immutable custody, and every zero-authority field. The real
run must reconcile all 437,402 included paths and write nothing to `/data` or
Production.
