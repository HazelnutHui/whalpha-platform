# Architecture Decision Records

ADRs record material project decisions and their context.

## Status Values

- Proposed
- Accepted
- Superseded
- Rejected

## Format

Each ADR should include:

- Title
- Status
- Date
- Context
- Decision
- Consequences
- Alternatives Considered
