# Architecture Decision Records

ADRs preserve material decisions and their original evidence. A later ADR may
supersede future direction without deleting the historical fact that earlier
code or contracts were accepted.

Use [current context](../project/current-context.md) for volatile state,
[current status](../project/current-status.md) for actual capability, and the
[roadmap](../project/roadmap.md) for proposed sequencing. Do not infer that an
accepted ADR was deployed unless current operational evidence says so.
