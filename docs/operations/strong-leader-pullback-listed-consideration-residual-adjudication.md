# Strong-Leader Pullback Listed-Consideration Residual Adjudication

This network-disabled operation adjudicates only the three residual listed
merger-consideration identities from their frozen complementary evidence.

Run the repository-aware wrapper from a clean canonical checkout with absolute
owner-only input and output paths, a fixed UTC evaluation time, and `--execute`:

```bash
scripts/admin/adjudicate-strong-leader-pullback-listed-consideration-residual.sh \
  --original-plan /absolute/original/plan=... \
  --original-plan-custody-root /absolute/original-plan \
  --original-source /absolute/original/source=... \
  --original-source-custody-root /absolute/original-source \
  --prior-identity /absolute/prior/adjudication=... \
  --prior-identity-custody-root /absolute/prior \
  --residual-plan /absolute/residual/plan=... \
  --residual-plan-custody-root /absolute/residual-plan \
  --residual-source /absolute/residual/source=... \
  --residual-source-custody-root /absolute/residual-source \
  --consideration /absolute/consideration/adjudication=... \
  --consideration-custody-root /absolute/consideration \
  --output-root /absolute/output/adjudication=... \
  --output-custody-root /absolute/output \
  --evaluated-at 2026-09-14T06:00:00Z \
  --execute
```

Review each evidence path and the residual and cumulative match counts. Exact
reruns return `already_present`; a different report at the same target fails
closed.

The command makes no network request, rewrites none of the prior nine identity
decisions, and creates no terminal value, strategy result, `/data` or
Historical Coverage write, research admission, Candidate result, publication,
deployment, or scheduler change.
