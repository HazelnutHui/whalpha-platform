remaining listed-stock consideration identity cases.

Run the repository-aware wrapper with absolute formally retained inputs,
owner-only output custody, a fixed UTC evaluation time, and `--execute`:

```bash
scripts/admin/plan-strong-leader-pullback-listed-consideration-residual-source.sh \
  --original-plan /absolute/original/plan=... \
  --original-plan-custody-root /absolute/original \
  --identity-adjudication /absolute/identity/adjudication=... \
  --identity-adjudication-custody-root /absolute/identity \
  --consideration /absolute/consideration/adjudication=... \
  --consideration-custody-root /absolute/consideration \
  --submissions-package /absolute/sec-submissions/snapshot=... \
  --submissions-custody-root /absolute/sec-submissions \
  --output-root /absolute/residual/plan=... \
  --output-custody-root /absolute/residual \
  --evaluated-at 2026-09-14T05:00:00Z \
  --execute
```

The repository must be clean. All inputs and any completed output are formally
reread. Exact reruns return `already_present`; a differing report at the same
target fails closed.

The command does not access the network, acquire the planned Fifth Third file,
assign identity, calculate a terminal value or strategy result, write `/data`
or Historical Coverage, admit research, publish, deploy, or change a scheduler.
