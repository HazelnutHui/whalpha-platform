# Strong-Leader Pullback Method Diagnostics

This offline Dell operation exercises the frozen method over the reconstructed
development population without opening forward outcomes. It is a versioned
research audit, not a daily or interactive product path.

Run from the canonical Dell repository with exact absolute roots for canonical
data, reconstructed Membership, the development census, split actions, split
adjustments, the method-engineering launch review, and private output custody:

```bash
scripts/dev/run-project-python.sh \
  -m tip_api.services.strong_leader_pullback_diagnostics_cli \
  --data-root /absolute/canonical/data/root \
  --membership-shadow-root /absolute/reconstructed/membership \
  --development-census-root /absolute/development/census \
  --split-action-publication-root /absolute/split/action/publication \
  --split-adjustment-publication-root /absolute/split/adjustment/publication \
  --method-launch-root /absolute/private/method-launch/review=VERSION \
  --method-launch-custody-root /absolute/private/method-launch \
  --output-root /absolute/private/method-diagnostics/report=VERSION \
  --output-custody-root /absolute/private/method-diagnostics
```

The command disables network access, formally rereads the bound 287 Membership
partitions and canonical source publications, rejects partial cross-sections,
and writes one deterministic report with custody modes `0700/0400`. An exact
replay is idempotent and must return the existing identical report.

The first baseline took about 27 minutes because it validated roughly 5.31
million reconstructed Membership decision rows before calculating features.
Do not place that full reread on the daily product path. Any later recurring
calculation requires a separately designed incremental boundary with the same
fail-closed rules.

Success grants no outcome, parameter-selection, validation, Candidate,
publication, deployment, canonical-data-write, or Production authority. Before
acceptance, verify report SHA-256 and logical fingerprint, exact declared-path
reconciliation, owner-only modes, one report file, and no symlink or partial
residue.
