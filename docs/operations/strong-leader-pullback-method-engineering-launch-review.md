# Strong-Leader Pullback Method-Engineering Launch Review

This operation converts the immutable rejected performance gate into a
separate outcome-blind method-engineering boundary. It does not run the
strategy or open outcomes.

Run from the clean canonical Dell repository with the exact completed
pre-research review and owner-only custody roots:

```bash
scripts/admin/review-strong-leader-pullback-method-engineering-launch.sh \
  --pre-research-review /absolute/private/pre-research/review=VERSION \
  --pre-research-review-custody-root /absolute/private/pre-research \
  --output-root /absolute/private/method-launch/review=VERSION \
  --output-custody-root /absolute/private/method-launch \
  --reviewed-at YYYY-MM-DDTHH:MM:SSZ \
  --execute
```

The command requires a clean repository and records its exact revision. It
makes no provider request, reads no credential, and writes neither `/data` nor
Production. Success prints the source decision, fixed scope, unresolved formal
blockers, report hashes, and the narrowly authorized next action.

Before accepting the result, independently rerun the same command and confirm
`already_present`, identical hashes, directory/file modes `0700/0400`, exactly
one report file, and no partial or symlink residue.
