# Strong-Leader Pullback Research Admission V2

This Dell-only operation decides whether the frozen reconstructed dataset may
open development labels and development-only parameter selection. It does not
open validation, holdout, performance claims, Candidate activation, web
publication, or Production.

Run it only from a clean canonical repository. Supply the exact retained
development census, method diagnostic, five-year split-source custody, prior
split observation, five-year resolution shadow, canonical split publications,
and final terminal-reference report. The command disables network access and
formally rereads every supplied input before writing one owner-only immutable
report:

```bash
scripts/admin/review-strong-leader-pullback-research-admission-v2.sh \
  --development-census-root /absolute/development/census \
  --diagnostics-root /absolute/method/diagnostics/report=VERSION \
  --diagnostics-custody-root /absolute/method/diagnostics \
  --corporate-action-source-root /absolute/five-year/corporate-action/source \
  --prior-split-source-root /absolute/prior/split/source \
  --split-resolution-shadow-root /absolute/split/resolution/build=VERSION \
  --split-resolution-shadow-custody-root /absolute/split/resolution \
  --canonical-data-root /data/trading-intelligence-platform \
  --canonical-split-action-root /absolute/canonical/split/action \
  --canonical-split-adjustment-root /absolute/canonical/split/adjustment \
  --final-terminal-root /absolute/terminal/review=VERSION \
  --final-terminal-custody-root /absolute/terminal \
  --output-root /absolute/admission/review=VERSION \
  --output-custody-root /absolute/admission \
  --reviewed-at 2026-09-15T00:00:00Z \
  --execute
```

The feature count has three distinct layers and must never be collapsed into
one subtraction: 287 chronological sessions, 20 feature-window warm-up
sessions, 267 sessions with rankable Primary cross-sections, and 254 complete
cross-sections after 13 whole-session exclusions. The minimum gate applies to
the final 254, not 274.

The split-source check treats provider action IDs and the provider historical
adjustment factor as observation metadata. Only `split_from`, `split_to`,
effective date, ticker, and action type define the mechanical term comparison.
Any genuinely added term must be exact-date resolved and have zero Primary
included paths, or the review stops. Unresolved-action windows remain excluded;
no action is inferred from a price discontinuity.

An identical rerun must return the existing report with the same SHA-256 and
logical fingerprint. No credential is read, and all external requests,
forward outcomes, metrics, parameter selections, canonical writes, and
Production writes remain zero.
