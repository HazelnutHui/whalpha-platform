# Strong-Leader Pullback Source Acceptance Sample

## Boundary

This operation builds ADR 0223's finite provider-neutral query population from
the formally retained ADR 0221 blocker census and both inactive-lifecycle
anchors. It is network-prohibited, reads no credential, and writes only a new
owner-only immutable report outside `/data`.

The output custody root must be an existing mode-`0700` directory. The direct
`build=*` target must be absent or an exact completed object. Run from a clean
canonical checkout through `scripts/dev/run-project-python.sh`; use the CLI's
aggregate completion output and the formal report reader for postflight.

The operation must recover all 20 unassigned action cases and all 64
five-session lifecycle-crossing cases. Any missing lifecycle source occurrence,
identifier inconsistency, unexpected selection, target drift, symlink, or
malformed source stops before completion. Individual case rows are private
query locators, not identity assignments or terminal facts.

Building this sample does not authorize contacting a provider. A later pilot
must be separately bounded to this exact sample fingerprint, declare the
provider entitlement and requested fields, retain explicit unsupported/missing
states, and remain outside canonical custody until reviewed.
