# 专业量化研究行动框架 V1.0

> 从研究命题、点时数据、特征工程到样本外验证、组合实施与模型退役的完整手册

**文档状态：** 行动基线  
**版本：** 1.0  
**生效日期：** 2026-09-02  
**适用范围：** 中低频股票、ETF、跨资产状态研究，以及独立的上市期权表达研究  
**核心目标：** 建立可证伪、可复现、成本后可实施、可持续监控的量化研究能力

---

## 使用说明

本框架是一套独立的专业量化研究方法，不以任何现有网站、前端产品或单一数据商为边界。免费与付费数据均可采用；采购标准是能否显著降低研究不确定性、填补关键历史或改善执行真实性，而不是字段数量或价格高低。

框架不承诺必然产生超额收益。合格成果包括：通过验证的策略、被证伪的假设、被识别的数据缺陷、被量化的成本上限，以及明确的停用结论。失败但可复现的研究仍是有效资产。

量化研究的本质是对条件概率分布和决策后果进行估计，而不是精确预测下一价格。最终对象不是“信号看起来有效”，而是：

> 在给定市场状态、可交易池、执行时点与约束后，某项行动的成本后收益分布是否稳定优于明确基准，并且风险、容量与失效条件是否可接受。

## 一、十二条总原则

1. **先冻结问题，再观察答案。** 假设、样本、参数范围、基准、成本和通过条件应在正式检验前登记。
2. **点时正确优先于数据量大。** 错误的历史成分、修订后财务数据或未来已知事件会使大样本失去意义。
3. **研究池是策略的一部分。** 股票池必须在结果出现前定义，并保留每日真实成员、退出与退市记录。
4. **特征与标签严格隔离。** 信号截点之后才能知道的事实只能进入结果成熟层，不能进入特征。
5. **先建立简单基准，再增加复杂度。** 规则、排序、线性模型无法被复杂模型稳定超越时，复杂模型不具备上线理由。
6. **样本外结果高于样本内美观。** 参数平台高于最佳单点；多时期稳定高于一次高收益。
7. **成本是模型的一部分。** 点差、滑点、冲击、借券、融资、期权 IV 与时间损耗不能在回测完成后再补充。
8. **股票观点与期权表达分离。** 股票未来收益不能被称为期权收益；期权需要独立链数据、定价、Greeks 和执行模拟。
9. **相关关系不自动等于因果。** 价格与成交量是交易行为代理，不应被误称为资金流；跨资产联动需要稳定性和时序检验。
10. **风险调整不用于掩盖弱信号。** 仓位管理可以改善生存性，但不能把没有成本后优势的策略变成有效策略。
11. **所有结果必须可重放。** 数据版本、代码版本、参数、环境、随机种子、成本模型和输出指纹必须可追溯。
12. **退役与开发同等重要。** 漂移、容量下降、执行恶化或经济机制失效必须触发降级、暂停或退役。

## 二、研究对象与成功标准

### 2.1 研究对象

完整研究系统包含四个相互分离的对象：

| 对象 | 回答的问题 | 典型输出 |
| --- | --- | --- |
| 市场状态 | 当前环境支持哪些风险和策略风格 | Regime、风险预算、策略开关或权重 |
| 横截面选择 | 同一时点哪些证券相对更具优势 | 排名、分组、条件概率、证据与反证 |
| 时间序列择时 | 单一证券或资产何时进入、等待、退出 | 触发、确认、失效、持有期限 |
| 交易表达 | 如何把观点转换为可实施头寸 | 股票、Call/Put、价差、Covered Call、DTE 与仓位 |

市场状态不应代替个股策略，个股排名不应代替入场条件，股票信号不应代替期权策略。

### 2.2 研究成功的必要条件

一项研究进入候选上线状态，至少需要同时满足：

- 经济机制可说明，并能提出反例；
- 点时数据与标签具备完整谱系；
- 相对明确基准存在样本外增量；
- 结果对合理参数、时间段、市场状态和证券子集不过度敏感；
- 成本、容量、延迟和执行限制后仍保留正向期望；
- 风险集中、极端损失与回撤处于预先设定的边界；
- 影子运行能复现信号、成交假设与监控数据；
- 失效条件、暂停条件和退役条件已定义。

单一高 Sharpe、漂亮权益曲线、较低 p 值或少数成功案例都不构成充分证据。

### 2.3 核心目标函数

研究目标应从毛收益升级为成本后效用：

```text
NetReturn = GrossReturn
          - Commission
          - BidAskCost
          - Slippage
          - MarketImpact
          - BorrowAndFinancing
          - StrategySpecificCost

ResearchUtility = E(NetReturn)
                - λ1 × DownsideRisk
                - λ2 × Turnover
                - λ3 × Concentration
                - λ4 × ModelUncertainty
```

风险偏好参数只能在研究前确定或在预先定义的场景中比较，不得为了美化结果事后调整。

## 三、端到端研究生命周期

### 3.1 标准流程

```text
研究授权与约束
    ↓
可证伪假设与经济机制
    ↓
数据需求与点时可用性审查
    ↓
原始事实 → 标准化 → 规范数据 → 特征/标签
    ↓
探索性诊断与简单基准
    ↓
预注册策略、参数族、成本与通过门槛
    ↓
开发集建模与有限选择
    ↓
参数锁定 → 验证集检验 → 单次保管留出集
    ↓
组合、容量、执行与压力测试
    ↓
影子运行 / 模拟交易
    ↓
条件上线 → 持续归因、漂移与衰减监控
    ↓
维持 / 降级 / 暂停 / 退役 / 新版本重研
```

### 3.2 生命周期状态

| 状态 | 含义 | 允许动作 |
| --- | --- | --- |
| idea | 研究想法尚未冻结 | 讨论机制、数据与反例 |
| preregistered | 假设与检验方案已冻结 | 建设数据、执行预定研究 |
| data_blocked | 关键点时数据或标签不完整 | 补数据，不生成绩效结论 |
| development | 仅开发区间开放 | 有限参数选择、误差分析 |
| validation | 参数锁定 | 检验泛化，不得重新调参 |
| holdout_review | 单次保管留出评估 | 只评估锁定版本 |
| validated_research | 研究门槛通过 | 组合、容量、影子审查 |
| shadow | 真实时间影子运行 | 对比预期与实际执行 |
| conditional_live | 小风险预算上线 | 严格限额与快速回滚 |
| active | 运行证据充分 | 受控扩容和持续监控 |
| degraded / paused | 证据或运行异常 | 停止新增风险、调查原因 |
| rejected / retired | 不再满足条件 | 保留全部证据，不重写历史 |

状态转换必须由证据门槛触发，不能由主观偏好或短期盈亏自动触发。

多 Agent 研究只能扩展每个阶段内的工作吞吐，不能压缩或绕过这些
阶段。提出想法的数量可以很大，允许接触收益数据的实验数量必须有限、
预先登记并计入同一策略家族的总搜索预算。

## 四、研究授权与策略任务书

每项研究开始前应形成一页式任务书，至少冻结以下内容：

- **目标：** 预测、筛选、择时、风险控制或交易表达；
- **资产与市场：** 股票、ETF、期权或跨资产变量；
- **决策频率：** 日频、小时级或更高频；
- **信号截点：** 收盘、开盘前、盘中固定时点或事件时点；
- **最早可成交时点：** 必须晚于全部特征的真实可用时间；
- **目标持有期：** 主窗口与次窗口；
- **可交易池：** 点时成员、价格、流动性、上市历史和排除规则；
- **比较基准：** 市场、行业、同类候选、现有策略或无交易；
- **目标标签：** 收益、超额收益、MFE、MAE、回撤或事件结果；
- **成本场景：** 基准、压力和盈亏平衡成本；
- **参数搜索预算：** 组合数、模型数、特征数与停止规则；
- **通过/失败条件：** 统计、经济、风险、覆盖与稳定性门槛；
- **失效假设：** 哪些观察会推翻机制；
- **所有权与版本：** 研究标识、模型所有权、代码版本和数据版本。

策略池的“个人化”可以形成真正优势，但必须先于结果定义。合理方式包括流动性带、波动特征、行业结构、催化剂类型、持有期限与风险承受范围；不合理方式包括根据回测赢家事后删掉失败证券。

## 五、专业数据基础

### 5.1 数据层级

数据应分层保管，任何层都不应覆盖上游事实：

| 层级 | 内容 | 关键要求 |
| --- | --- | --- |
| Raw | 供应商原始响应或可审计原始事实 | 不改写；保留许可允许的必要证据 |
| Normalized | 字段、类型、单位、时区与状态标准化 | 可重复映射；异常显式化 |
| Canonical | 稳定 ID 下的规范事实 | 去重、版本化、点时、冲突治理 |
| Membership | 每日可交易池与研究池决定 | 每个证券均有纳入、排除或隔离结果 |
| Adjustment | 拆股、分红、重组与收益桥接 | 原始价格、价格收益、总收益分离 |
| Feature | 截点前可用的研究特征 | 版本化公式、窗口、滞后和缺失规则 |
| Label | 截点后成熟的结果 | 与特征物理或逻辑隔离 |
| Research Result | 参数、统计、归因与决策 | 绑定全部输入和代码指纹 |
| Serving / Decision | 经批准的有限消费数据 | 不能反向改写研究证据 |

### 5.2 点时数据的四个时间

专业研究至少区分：

1. **有效时间：** 事实对市场或法律关系开始生效的时间；
2. **公开/源可用时间：** 数据源声称该事实可获得的时间；
3. **系统摄取时间：** 数据被研究基础设施观察并保存的时间；
4. **研究截点：** 某个信号允许使用信息的最后时间。

历史回填时间晚于有效时间并不等于泄漏。只有在研究截点前具备可靠可用性语义的事实才能进入特征。无法证明历史可用时间的记录，可用于事后结果核对，但不能伪装成当时已知信息。

### 5.3 身份、存续与成分

- 永久连接键应采用稳定 `instrument_id`；ticker 只作为生效期内显示标识。
- 每日研究池必须保存真实成员，不能用今天的成分回放历史。
- 上市、停牌、退市、并购、换股、分拆、代码更换和证券类别变化必须显式建模。
- 不明消失不能被静默删除，也不能自动赋予零收益。
- 退市、并购或复杂公司行动跨越结果窗口时，应按预定规则结算或隔离。
- 存活偏差、选择偏差和历史重分类必须作为独立质量门禁。

### 5.4 公司行动与调整

原始 OHLCV 不应被调整序列覆盖。至少保留：

- 未调整价格与成交量；
- 拆股价格乘数和股数/成交量乘数；
- 价格收益桥；
- 含分红总收益桥；
- 公司行动来源、首次观察、修订和冲突状态；
- 调整方法版本和基准日期。

价格收益与总收益是不同研究对象。中短期技术策略通常以可成交价格路径为核心，但跨除权窗口仍需准确调整和现金分配处理。

### 5.5 数据家族优先级

专业数据建设建议按以下顺序推进：

1. **身份、交易日历、生命周期、公司行动与每日成分；**
2. **股票 EOD、报价/NBBO、分钟数据与交易状态；**
3. **点时基本面、财报日期、修订记录和分析师一致预期；**
4. **期权历史链、bid/ask、成交、OI、IV、Greeks、调整与行权事件；**
5. **宏观发布日期、初值与修订值、利率曲线、信用和跨资产价格；**
6. **新闻、公告、电话会文本与事件分类；**
7. **替代数据。**

顺序反映基础依赖，而不是投资价值高低。没有身份、点时和公司行动治理时，更多另类字段只会扩大不可控误差。

### 5.6 历史深度

| 研究用途 | 建议最低边界 | 更可靠目标 |
| --- | --- | --- |
| 初步建模和机械正确性 | 约 252 个连续交易日 | 只够基础时间切分，不作为完整市场周期证据 |
| 日频 1–5 日股票策略初步研究 | 约 504 个连续交易日 | 3–5 年点时数据，覆盖不同波动与趋势环境 |
| Regime、行业轮动、宏观联动 | 至少一个以上完整周期片段 | 5–10 年或更长，重点是制度一致和可用性语义 |
| 财报/事件研究 | 多年且每类事件有足够独立样本 | 跨多个盈利和利率环境 |
| 期权横截面与期限结构 | 至少覆盖多种波动环境 | 2–5 年高质量历史链，事件样本另计 |

时间长度不能代替独立样本数量。高度重叠的 5 日标签、同日数千股票和同一行业簇不能被当作完全独立观察。

### 5.7 数据质量门禁

每个数据家族必须报告：

- 覆盖日期、证券数、字段覆盖率和缺失模式；
- 重复业务键、孤立引用、异常价格和异常成交量；
- 交易日连续性、时区和截止时间一致性；
- 公司行动前后价格与股数守恒检查；
- 修订率、延迟分布与供应商更正历史；
- ticker 冲突、稳定 ID 冲突与未知生命周期；
- 数据版本、文件哈希、模式版本和来源许可；
- 可用、降级、隔离与不可用于绩效的明确状态。

质量失败必须阻断研究或隔离受影响样本，不能以均值填充掩盖结构性缺失。

### 5.8 付费数据采购原则

付费数据不受“免费优先”限制，但采购必须对应明确研究缺口。评分维度建议包括：

| 维度 | 审查问题 |
| --- | --- |
| 点时完整性 | 是否保留历史可用时间、修订和退市证券 |
| 覆盖 | 资产、证券状态、日期、字段和事件是否完整 |
| 语义 | 字段定义、调整方法和时间戳是否可验证 |
| 质量 | 错误率、修订率、异常处理和支持响应如何 |
| 交付 | 批量历史、增量、速率、SLA 和重试是否适合 |
| 许可 | 本地保留、衍生研究、展示、备份和终止义务是否清楚 |
| 可替换性 | 稳定 ID 和内部规范层能否避免供应商锁定 |
| 经济价值 | 是否提高有效样本、降低泄漏或显著改善执行模拟 |

只有在“预期研究价值 > 数据成本 + 集成成本 + 维护成本”时采购。价格不是主要障碍，无法证明边际研究价值才是主要障碍。

## 六、标签设计：先定义要预测什么

### 6.1 标签原则

- 标签必须对应真实决策时点和可成交价格。
- 收盘后信号通常不得用同一收盘价作为无摩擦成交价。
- 主标签、次标签、风险标签和路径标签应在研究前冻结。
- 未成熟、缺失、跨公司行动或不可成交的标签必须显式标记。
- 股票、ETF、期权和组合结果采用独立标签体系。

### 6.2 股票策略常用标签

| 类型 | 定义示例 | 用途 |
| --- | --- | --- |
| 绝对收益 | 次日开盘至第 h 日收盘 | 实际方向与持有期 |
| 市场超额 | 股票收益减 SPY 同期收益 | 剥离市场方向 |
| 行业超额 | 股票收益减点时行业基准 | 剥离行业暴露 |
| 同类对照差 | 信号组减同日合格非信号组 | 检验结构的增量价值 |
| MFE | 持有期内最大有利变化 | 盈利空间和止盈研究 |
| MAE | 持有期内最大不利变化 | 止损、仓位和追高风险 |
| 首触标签 | 先触目标、止损或到期 | 路径依赖型策略 |
| 回撤/尾部 | 最差路径、跳空或极端分位 | 脆弱性和风险控制 |

同类对照通常比全市场对照更能回答“新增结构是否有价值”。例如，强势股回撤应与同日未出现回撤触发的合格强势股比较，而不只与全市场比较。

### 6.3 标签窗口与重叠

同时评估 1、3、5、10、20 日窗口时，应预先指定主窗口。重叠窗口需要 purging、embargo、按日期/区块推断或非重叠敏感性检验。横截面大量证券不等于大量独立日期。

### 6.4 有效周期

因子的有效周期应定义为成本后增量稳定存在的连续窗口，而不是收益最高的单一持有日：

```text
AlphaDecay(h) = E[BenchmarkAdjustedReturn at horizon h | signal]
NetAlpha(h)   = AlphaDecay(h) - RoundTripCost(h)
```

主持有期应位于净优势的平台区间，并同时考虑：

- 置信区间是否仍高于零；
- 排名 IC 是否持续；
- 反转是否开始；
- 换手与成本是否急升；
- 不同 Regime 下是否一致；
- 参数与退出日微调是否改变结论。

## 七、特征工程

### 7.1 特征工程前后

| 阶段 | 状态 | 主要问题 |
| --- | --- | --- |
| 原始数据 | 供应商字段、不同时间戳、不同单位和缺失状态 | 不能直接比较、可能泄漏、身份不稳定 |
| 规范化 | 统一类型、时区、单位、状态和稳定 ID | 仍是事实，不等于研究特征 |
| 特征构造 | 计算收益、波动、趋势、估值、事件等 | 必须绑定窗口、滞后、截点和缺失规则 |
| 横截面/时序变换 | winsorize、rank、z-score、行业中性化 | 必须只用当时可见总体 |
| 特征注册 | 版本、公式、方向、来源和质量记录 | 形成可复现研究输入 |
| 模型输入 | 经选择的特征矩阵 | 不应包含标签、未来修订或样本外信息 |

特征工程不是“制造更多指标”，而是把不稳定原始事实转换为有明确经济含义、可比较、可复现、点时安全的研究变量。

### 7.2 特征注册表

每个特征至少记录：

- `feature_id`、版本和所有权；
- 经济机制与预期方向；
- 原始字段、稳定 ID 和可用时间；
- 计算公式、窗口、最小观察数和滞后；
- 调整口径、价格口径和基准；
- 缺失、异常、截尾和隔离规则；
- 横截面或时间序列标准化方式；
- 行业、规模、beta、波动和流动性中性化规则；
- 适用研究池、频率和信号截点；
- 首次登记日期、代码版本和单元测试；
- 已知反例、失效风险和相关特征簇。

### 7.3 核心特征族

1. **相对强度与动量：** 1/5/20/60/120/252 日收益、市场/行业超额、残差动量；
2. **趋势与位置：** 均线斜率、距离高点、突破距离、ATR 位置、延伸程度、回撤深度；
3. **成交参与：** 成交量相对中位数、成交金额、上涨/下跌量、持续性和异常成交；
4. **波动与尾部：** 实现波动、下行波动、跳空、偏度、尾部频率、相关性突变；
5. **流动性与容量：** 点差、报价深度、成交金额、Amihud 类冲击代理、可交易比例；
6. **市场与行业状态：** 宽度、风险偏好、利率/信用、行业相对趋势、相关性聚集；
7. **基本面：** 增长、利润率、现金转换、资本效率、杠杆、盈利质量和修订；
8. **估值：** 点时横截面、历史自身区间、行业相对和简化估值区间；
9. **事件：** 财报距离、实际值与点时预期差、指引变化、宏观日历和价格反应；
10. **期权：** ATM IV、期限结构、偏斜、IV-RV、OI、成交、点差和 Greeks。

价格与成交量特征只能被称为价格、成交或交易活动代理。没有持仓与申赎等直接证据时，不应标记为资金流。

### 7.4 标准化与中性化

- 横截面 rank 或稳健 z-score 通常优于未经处理的绝对值；
- winsorization 边界必须按训练期或当日点时横截面计算；
- 行业中性化用于识别个股残差优势，但行业本身可能是策略收益来源，因此应同时报告中性化前后结果；
- 规模、beta、波动、价格和流动性暴露必须归因，不能被误称为独立 alpha；
- 缺失状态本身可能含信息，但只有具备机制和点时一致性时才能作为特征；
- 在全历史上计算均值、分位数或标准差后再切分数据属于泄漏。

### 7.5 冗余与有效维度审计

在选择前必须先完成多变量冗余与有效维度审计。两两相关性较低不代表
信息独立；多个动量、趋势或波动变体可能共同落在同一个潜在方向。最低
诊断包括：

- 只使用当时可见横截面或训练区间拟合的 rank／稳健 z-score；
- Pearson、Spearman、尾部相关和缺失共现矩阵；
- 依据经济机制命名的因子族，以及数据驱动的层次聚类；
- 条件数、VIF 或等价的多重共线性诊断；
- 在 Development／训练区间单独拟合的 PCA，有效维度、解释方差和载荷；
- 将冻结的标准化、聚类或 PCA 变换原样应用于后续时间段，禁止全样本拟合后再切分；
- 对每个保留因子说明其相对同簇代表变量提供的增量信息。

PCA 用于回答“表面上的 N 个因子实际包含多少独立方向”，不能凭主成分
图形本身证明 Alpha，也不能把难以解释的主成分自动提升为策略输入。网站
在阶段完成后应公开标准化口径、因子簇、相关性热图、二维 PCA 载荷图、
解释方差、有效维度和保留／淘汰原因；未完成时必须明确显示未计算。

### 7.6 特征选择与复杂度预算

首轮研究宜从约 20–30 个经济含义清晰的核心特征开始，同一相关簇选取代表变量。交互项优先限制在 5–8 个有明确机制的组合，例如：

- 高相对强度 × 有序缩量回撤；
- 行业强势 × 个股重新加速；
- 高波动环境 × 防御行业相对强势；
- 低估值 × 盈利质量改善 × 价格企稳；
- 财报临近 × 期权 IV 昂贵 × 持仓方向风险。

自动生成数百因子、所有窗口和所有交互会迅速耗尽独立证据。因子数量必须进入多重检验账本。

### 7.7 因子、模型与策略表达三层分离

长期研究采用三个独立版本层，而不是先固定若干策略名称：

1. **因子发现层：** 定义和检验点时测量，输出方向因子、条件变量、中性化变量、风险守门或执行输入；
2. **模型构建层：** 用少量已准入、非冗余因子形成排名、概率、条件分布或风险状态；
3. **策略表达层：** 将锁定模型转换为 Universe、入场、等待、失效、退出、持有、仓位、成本、容量和组合约束。

长期可以登记新的因子与模型家族，但每一批读取收益的研究必须预先限定候选定义、参数、交互、试验次数和停止规则。开放研究方向不等于开放单次搜索预算。一个因子有效不等于模型有效，一个模型有效也不等于存在成本后可实施的策略表达。

突破、回撤、延续、反转、价值、防御、事件和跨资产等名称只表示可提出命题的研究领域。最终模型的形式、数量和名称由受治理的证据链产生，不由预先排列的策略清单决定。

## 八、单因子研究与假设筛选

### 8.1 因子诊断

每个候选因子至少检查：

- Pearson IC 与 rank IC；
- IC 均值、波动、t 值、命中率和时间序列；
- 分位数组合收益、单调性和顶部/底部差；
- 1/3/5/10/20 日衰减与反转；
- 市场、行业、规模、波动、价格和流动性中性化前后；
- 不同 Regime、年份、行业和流动性层的稳定性；
- 换手、持仓集中、尾部损失和拥挤风险；
- 正常、压力与盈亏平衡成本；
- 缺失率、数据修订和异常值敏感性。

### 8.2 机制、证据与反证

因子说明必须同时包含：

- 预期机制；
- 观察到的支持证据；
- 反面证据；
- 替代解释；
- 最容易失效的市场状态；
- 可能只是风险补偿、行业暴露或流动性溢价的部分。

“过去上涨，因此继续上涨”不构成完整机制。更合格的表达是：领导力持续、供需路径、信息扩散、风险偏好或行为偏差在特定环境中形成条件优势，同时承认拥挤与反转风险。

### 8.3 预测关系与因果主张

交易策略只需要可重复的条件预测关系，不必强行证明完整因果机制；但任何因果表述都需要更高证据标准。财报、宏观和政策事件研究应额外处理：

- 事件公告的精确时点、预期值、初值与后续修订；
- 事件前趋势、同日其他冲击和选择进入事件样本的机制；
- 事件窗口、安慰剂窗口和未受影响对照；
- difference-in-differences、工具变量或其他识别方法的适用假设；
- 多事件重叠、提前泄漏和市场已定价程度；
- 统计关联、预测增量与因果解释的分层结论。

无法识别因果时，应使用“条件关联”“领先信息”或“价格反应代理”等准确语言。预测可用性与因果真实性必须分别报告。

### 8.4 从因子到策略

因子有效不等于策略可实施。策略还需要：

- 明确可交易池；
- 触发、等待、进入与失效状态；
- 同日候选排序和头寸上限；
- 重复信号、冷却期和再入规则；
- 组合冲突处理；
- 成本、容量和执行模型；
- 退出与风险覆盖规则。

## 九、模型与策略构建

### 9.1 不采用一个总分或固定策略清单服务所有研究

不同机制、标签、风险与有效周期不能被预先压缩进一个总分，也不应被永久锁定为若干命名通道。突破、回撤、延续、反转、价值和防御等可以是命题标签；只有经过因子发现、模型构建和策略表达三层证据链的版本，才成为可评价的研究对象。跨模型总排名容易把不可比较的对象压缩成缺乏意义的数字。

更合理的输出是多个独立轴：

- 动量质量；
- 入场位置与追高风险；
- 市场/行业适配；
- 风险脆弱性；
- 股票与期权可交易性；
- 估值与基本面；
- 事件风险；
- 数据覆盖与模型不确定性。

结论应解释“为何高或低”，而不是只显示一个总分。

### 9.2 模型复杂度阶梯

1. **透明规则与分组统计；**
2. **横截面排序与线性/广义线性模型；**
3. **正则化模型和有限交互；**
4. **树模型、梯度提升和非线性集成；**
5. **状态空间、概率模型或更复杂时序方法；**
6. **深度学习或大规模替代数据模型。**

每一级只有在冻结数据和相同样本外条件下，稳定提高成本后效用、校准度或风险控制时才可晋级。复杂模型必须与最后一个简单基准并列报告。

### 9.3 预测形式

优先预测以下对象，而非单一点价格：

- 正收益或超额收益概率；
- 条件收益分布或分位数；
- MFE/MAE 与首触概率；
- 排名分位；
- 风险状态与不确定性；
- 交易是否值得执行的净效用。

概率输出必须校准，可使用可靠性曲线、Brier score、log loss 和分组实际频率检查。方向准确率不能代替收益分布和成本。

### 9.4 个性化与进取型模型

个人风格可以体现在：

- 策略专属可交易池；
- 1–5 日爆发段与追高风险的权衡；
- 对行业轮动、相对领导力和价格路径的偏好；
- 对错过机会和错误追入的不对称损失；
- 股票观点的期权表达偏好；
- 明确的风险预算和持仓数量。

进取型模型仍需更严格的证据和更小的初始风险，不应通过放宽样本外、成本或尾部约束获得“侵略性”。模型界面或报告应显示“个人研究、版本、参数、验证状态、适用环境和失效风险”。

### 9.5 市场状态与跨资产联动

宏观和跨资产变量适合作为条件层，而不是首个无约束预测模型。推荐顺序：

1. 先证明个股或行业结构在自身层面有增量；
2. 再检验利率、信用、美元、黄金、能源、加密资产或高 beta 风险指标是否改变该策略的条件分布；
3. 使用滞后、发布日期与交易时区正确的点时变量；
4. 比较无 Regime、简单 Regime 和复杂 Regime 的样本外增量；
5. 在样本不足时只降低风险或标记环境，不做激进方向预测。

跨资产关系容易发生结构断裂。滚动相关性、领先滞后、子样本稳定性和机制解释必须同时存在，不能把偶然联动包装为因果策略。

## 十、专业回测引擎

### 10.1 回测必须模拟真实时间

每个交易日按以下顺序推进：

1. 推进市场时钟；
2. 载入截点前可用的数据版本；
3. 更新点时研究池；
4. 计算特征与信号；
5. 生成订单意图；
6. 在最早合法成交时点应用报价、成交量和成本；
7. 更新持仓、现金、风险、公司行动和到期事件；
8. 记录未成交、部分成交、拒绝和异常；
9. 只在未来路径到达后成熟标签和绩效。

向量化筛选可用于研究加速，但最终绩效必须由事件顺序正确的组合模拟器复核。

### 10.2 必须覆盖的现实约束

- 停牌、无报价、涨跌异常与不可成交；
- 次日跳空和收盘信号的成交延迟；
- 每日成交量参与率和头寸容量；
- bid/ask、滑点、冲击和费用；
- 退市、并购、分红、拆股和换股；
- 重复信号、重叠持仓和现金占用；
- 行业、单票、beta、波动与流动性限制；
- 借券可用性、借券费和强制回补；
- 订单类型、价格改善和未成交概率；
- 期权到期、提前行权、指派和合约调整。

### 10.3 研究结果与组合结果分离

信号层应回答“条件优势是否存在”；组合层应回答“多个信号在资金、风险与相关性约束下如何表现”。组合规则不得被用于掩盖单信号无效，也不能在留出集上反复优化。

## 十一、交易成本、容量与执行

### 11.1 成本分解

股票和 ETF 至少包含：

- 手续费和监管费用；
- 买卖价差的一半或更保守假设；
- 下单时延和价格滑点；
- 与订单规模/成交量相关的市场冲击；
- 借券和融资；
- 现金拖累与再平衡成本。

简单冲击场景可表示为：

```text
Impact ≈ k × Volatility × sqrt(OrderValue / DailyDollarVolume)
```

该式只能作为经校准的近似。参数必须来自实际成交、报价或可信外部研究，并进行压力测试。

### 11.2 固定成本场景与盈亏平衡

研究阶段应同时报告：

- 0 bps：机械上限，仅用于诊断；
- 低成本场景：高流动性理想执行；
- 基准场景：可实现的常态执行；
- 压力场景：扩大点差、延迟和冲击；
- 盈亏平衡成本：使净期望降至零的单边或往返成本。

若基准成本接近盈亏平衡成本，策略不具备足够安全边际。

### 11.3 换手控制

控制手段包括：

- 排名缓冲区与持仓滞后；
- 最低预期净优势；
- 最短持有与冷却期；
- 目标权重变化阈值；
- 只交易排名变化足够大的证券；
- 信号聚合而非逐因子重复交易；
- 将换手惩罚直接放入目标函数。

### 11.4 容量

容量应按证券、策略和组合分别估计：

- 订单占日均成交金额比例；
- 开盘/收盘时段真实可用成交量；
- 点差和冲击随规模的非线性变化；
- 候选集中与行业拥挤；
- 在压力日全部头寸退出所需天数；
- 资金扩大后策略边际收益衰减。

## 十二、防止未来函数与过拟合

### 12.1 常见泄漏路径

- 使用今天的指数、行业或股票池回放过去；
- 使用最新修订后的财报、宏观值或分类；
- 收盘信号以同一收盘价无摩擦成交；
- 在全样本上做标准化、缺失填充或特征选择；
- 通过未来公司行动修正当时信号；
- 随机切分具有时间依赖或重叠标签的数据；
- 让验证集或留出集参与参数、特征或模型选择；
- 删除退市、无结果或失败交易；
- 多次查看留出集后仍称其为未触碰样本。

### 12.2 时间切分

优先采用：

- 按时间顺序的开发、验证和单次保管留出；
- walk-forward 或 expanding-window 检验；
- 对重叠标签执行 purge 与 embargo；
- 按交易日/事件块做区块 bootstrap；
- 嵌套时间序列交叉验证处理模型和超参数选择；
- 留出集在参数锁定且验证通过后只打开一次。

### 12.3 多重检验

所有尝试都应进入实验账本，包括失败的因子、窗口、池子和变体。可采用：

- Holm–Bonferroni 或控制 FDR 的方法；
- White Reality Check 或同类数据窥探修正；
- Deflated Sharpe Ratio；
- Probability of Backtest Overfitting；
- 预先限制的参数组合数和模型预算。

修正后的统计显著性仍只是必要条件。经济意义、成本后效果和稳定性必须独立通过。

### 12.4 参数稳健性

合格参数应位于可解释的平台，而不是尖锐最佳点。必须检查：

- 相邻窗口和阈值是否保持方向；
- 轻微改变入场/退出是否导致结论崩溃；
- 去掉最佳年份、最佳行业或最大赢家后是否仍成立；
- 不同数据源或独立实现是否复现；
- 参数在验证和留出中是否保持锁定；
- 复杂度增加的增量是否超过估计误差。

### 12.5 对抗性检验

至少包含：

- 标签随机化和时间错位；
- 信号方向反转；
- 极端值和单一大赢家剔除；
- 缺失模式扰动；
- 成本和延迟加倍；
- 行业、规模和 beta 中性化；
- 日期拥挤与横截面依赖；
- 不同实现或独立 Oracle 复算；
- 数据修订和源冲突情景；
- 关键市场阶段删除和滚动起止日期。

若一个错误实现也能得到相似“好结果”，现有检验不足以证明策略有效。

### 12.6 有效样本量与统计功效

样本量规划应在正式检验前完成，并基于日期、事件簇和持仓重叠估计有效样本，而不是直接使用证券行数。至少报告：

- 预期信号率、独立日期数和每个 Regime 的观察数；
- 最小可检测经济效应与预期波动；
- 标签重叠、横截面相关和行业聚集造成的样本折扣；
- 置信区间在当前样本下可能达到的宽度；
- 继续收集数据的固定停止日期或固定观察数。

统计功效不足时，正确结论是“不确定”，而不是通过增加参数、放宽显著性或重复抽样制造确定性。

## 十三、统计报告与评价指标

### 13.1 必报指标

| 维度 | 指标 |
| --- | --- |
| 覆盖 | 可用/隔离/缺失样本、日期、证券、事件、成熟标签比例 |
| 收益 | 均值、中位数、分位数、累计收益、年化收益 |
| 风险 | 波动、下行波动、最大回撤、尾部损失、MAE |
| 风险调整 | Sharpe、Sortino、Calmar 及其置信区间 |
| 相对价值 | 市场/行业超额、同类对照差、alpha/beta 暴露 |
| 路径 | MFE、MAE、命中率、盈亏比、首触概率、持有期衰减 |
| 交易 | 换手、成本、滑点、未成交、容量和持仓天数 |
| 稳定性 | 年份、Regime、行业、规模、流动性和参数邻域 |
| 集中 | 前十贡献、最大赢家依赖、日期/行业/单票集中 |
| 概率 | 置信区间、经修正 p 值、校准度和预测不确定性 |

### 13.2 报告顺序

报告应按以下顺序呈现：

1. 研究问题与冻结假设；
2. 数据覆盖、缺失和点时限制；
3. 基准与对照组；
4. 主指标及置信区间；
5. 成本后结果与盈亏平衡成本；
6. 稳定性和参数平台；
7. 风险、回撤和集中；
8. 支持证据、反证和替代解释；
9. 失败门槛与当前生命周期状态；
10. 下一步只允许的动作。

## 十四、组合构建与风险管理

### 14.1 从预测到仓位

仓位应同时考虑：

- 预测优势与置信度；
- 波动、流动性和跳空风险；
- 与现有持仓的相关性；
- 行业、风格、beta 和事件集中；
- 预期持有期、退出容量和成本；
- 模型不确定性和当前 Regime。

仓位规模可从等风险或波动缩放起步，再逐步引入预期收益。估计误差大时，基于预测收益的激进最优化通常不稳定。

### 14.2 风险预算

应预先定义：

- 单票、单行业、单策略和总组合上限；
- 单日新增风险、总 delta/beta、波动和流动性预算；
- 财报、宏观和相关事件暴露；
- 最大允许回撤与降风险路径；
- 压力日可退出比例；
- 模型降级时的仓位折扣；
- 数据异常时的 fail-closed 行为。

### 14.3 压力测试

至少覆盖：

- 指数急跌与相关性升至一；
- 利率/信用跳变；
- 高 beta 和半导体压力；
- 防御板块拥挤反转；
- 开盘跳空和流动性骤降；
- 波动率上升且期权点差扩大；
- 数据延迟、信号缺失和错误分类；
- 最大持仓同时触发退出。

### 14.4 稳健组合优化

协方差、预期收益和相关性都存在较大估计误差。组合构建应优先使用收缩估计、权重上限、风险预算、换手惩罚和情景约束；只有在样本外证明增量后，才采用更敏感的最优化。任何优化结果都应与等权、波动倒数和简单分层组合比较，并报告约束轻微变化时的权重稳定性。

## 十五、期权表达研究：独立于股票信号

### 15.1 最低数据要求

期权研究至少需要：

- 每个合约的稳定标识、标的、行权价、到期日和类型；
- 历史 bid/ask、成交、OI 和报价时间；
- IV、期限结构、偏斜与 Greeks；
- 标的价格、利率、分红和借券假设；
- 财报日期和重大事件；
- 合约调整、提前行权、指派和到期结算；
- 可交易性、最小跳动与真实成交规则。

缺乏历史链时，只能描述股票观点与静态 payoff，不能声称某种期权表达具有历史收益优势。

### 15.2 研究对象

不同表达必须分别比较：

- Long Call / Long Put；
- ATM、轻度 ITM、轻度 OTM；
- Call/Put Debit Spread；
- Calendar 或其他定义风险买方结构；
- Covered Call；
- 不同 DTE，包括较长期与 LEAPS；
- 到期前退出、事件前退出和持有至到期。

裸卖期权不进入初始研究范围。卖方表达优先限定为有覆盖或定义风险结构。

### 15.3 期权标签与归因

期权收益应分解为：

- 标的方向贡献；
- delta/gamma 路径；
- theta 时间损耗；
- vega 与 IV 变化；
- skew 和期限结构变化；
- bid/ask 与滑点；
- 事件跳变；
- 提前行权、指派和分红影响。

策略比较应同时展示最大损失、盈亏平衡、概率分布、资本占用和尾部风险。DTE 与 moneyness 应由股票观点持续时间、IV 状态、催化剂和风险预算共同决定，不应形成单一永久最佳答案。

## 十六、从研究到上线的门禁

### 16.1 数据门禁

- 点时身份、成分、价格、公司行动和存续完整；
- 特征暖机和标签成熟区间充分；
- 数据质量和隔离比例低于预定阈值；
- 数据版本、许可和可重建性明确。

### 16.2 研究门禁

- 假设、参数预算和主指标已预注册；
- 简单基准已建立；
- 样本外与多重检验通过；
- 成本后经济价值为正并有安全边际；
- 参数、时期、Regime 和子集稳定；
- 反证、失败案例和风险暴露已披露。

### 16.3 实施门禁

- 组合约束、容量、执行和异常路径已模拟；
- 影子运行复现率和时延合格；
- 监控、告警、回滚和责任边界明确；
- 版本化信号、订单意图和实际成交可归因。

### 16.4 条件上线

首次上线应采用最小风险预算，并设定：

- 固定观察期；
- 最大仓位与损失；
- 不允许临时增加参数或规则；
- 预期信号率、成本和滑点区间；
- 自动暂停的数据与风险条件；
- 完成审查前不扩容。

通过研究门禁不自动等于允许交易。上线是独立决策。

## 十七、监控、衰减与退役

### 17.1 监控层

| 层级 | 监控内容 |
| --- | --- |
| 数据 | 延迟、缺失、修订、分布、身份和公司行动异常 |
| 特征 | PSI/KS、均值、分位、相关结构和覆盖漂移 |
| 信号 | 数量、强度、行业/日期集中、年龄和触发率 |
| 模型 | IC、校准、残差、置信度和解释贡献漂移 |
| 交易 | 成交率、点差、滑点、冲击、容量和换手 |
| 组合 | 收益归因、beta、行业、因子、尾部和回撤 |
| 策略 | 成本后优势、Regime 条件、衰减与竞争基准 |

### 17.2 衰减诊断

衰减应分为：

- **数据衰减：** 来源、字段、覆盖或修订改变；
- **特征衰减：** 分布或含义发生漂移；
- **模型衰减：** 条件映射不再校准；
- **执行衰减：** 成本、竞争和容量恶化；
- **市场结构衰减：** 机制或参与者行为变化；
- **组合衰减：** 相关性与集中放大了风险。

短期亏损不自动证明模型失效，短期盈利也不自动证明模型有效。诊断必须比较预注册的不确定性区间与连续观察窗口。

### 17.3 暂停与退役条件

- 关键数据质量门禁失败；
- 实际成本持续高于盈亏平衡边界；
- 样本外 IC、净收益或校准持续越过失效阈值；
- 风险、回撤或集中突破硬限制；
- 版本无法复现或输入谱系断裂；
- 经济机制发生可识别结构变化；
- 需要频繁临时修补才能维持结果；
- 更简单基准稳定替代复杂模型。

退役模型应保留全部历史、失败原因和适用环境，不能删除失败记录后重新包装为新研究。

## 十八、研究治理与可复现性

### 18.1 必备登记册

1. 数据源登记册；
2. 稳定身份与字段字典；
3. 特征注册表；
4. 标签注册表；
5. 实验与失败研究账本；
6. 模型与参数注册表；
7. 数据/代码/环境指纹；
8. 留出集保管记录；
9. 影子与上线版本记录；
10. 异常、回滚、暂停与退役记录。

### 18.2 复现包

每次正式结果必须能由以下材料重建：

- 研究任务书与预注册版本；
- 数据清单、范围、可用时间和内容哈希；
- 研究池、公司行动与标签规则；
- 特征版本和参数；
- 代码提交、依赖锁和运行环境；
- 随机种子、并行方式和确定性设置；
- 成本、容量、组合与执行假设；
- 完整日志、统计报告和独立复算结果。

### 18.3 AI 量化研究工厂边界

AI 可用于文献整理、假设扩展、数据需求设计、代码生成、测试设计、
异常排查、红队攻击和解释草稿，但不得把语言流畅度、Agent 数量或
Agent 共识当成证据。多个模型可能共享相同训练知识和研究惯性，不能
被统计上视为独立发现。

专业的 AI 研究工厂应满足：

- 高吞吐想法先按经济机制、特征、标签和预期持有期去重；
- 只有可证伪且有明确对照的想法获得有限实验和参数预算；
- 所有尝试与失败进入不可删除实验账本，真实试验次数不得隐藏；
- 假设、数据、实现、统计、成本、红队、独立复算和影子监控角色分离；
- 开发角色不能读取封存验证集和留出集，留出集不由研究 Agent 自主打开；
- 数值结果和晋级门禁由版本化确定性程序裁决，叙述不能覆盖失败证据；
- 新到达数据更新监控证据，模型变更必须创建新版本和新留出边界；
- 自动化最多推进到预先授权的研究状态，不能自动分配资本或执行订单。

AI 生成的公式、数据映射和回测代码仍必须经过：

- 点时与业务语义审查；
- 单元、性质和对抗性测试；
- 独立实现或 Oracle 复算；
- 真实小样本人工核对；
- 样本外和成本后检验。

最危险的错误通常不是语法错误，而是合理外观下的未来函数、错误对照、重复计数、错误调整和未披露选择。

## 十九、计算与工程实施原则

### 19.1 单机专业架构足够起步

中低频股票与期权研究可在高性能工作站上采用：

- Parquet/Arrow 规范数据；
- DuckDB、Polars、Pandas 或同类本地分析引擎；
- 内容寻址缓存和不可变分区；
- 元数据与实验注册数据库；
- 版本化 Python 环境与确定性测试；
- 单机多核并行。

无需为了“专业感”提前引入分布式系统。数据规模、内存、计算时间和失败恢复达到真实瓶颈后再扩展。

### 19.2 并行化边界

适合并行：

- 独立、已去重的假设规格和反例设计；
- 独立日期或证券分区的纯读取计算；
- 独立参数组合；
- bootstrap 重采样；
- 不同模型或验证折；
- 独立 Oracle 与压力场景。

不应无约束并行：

- 反复访问同一历史结果的自由假设或参数搜索；
- 共享验证或留出结果的研究 Agent；
- 有顺序状态依赖的回放；
- 共享可变缓存和写入；
- 供应商限速请求；
- 随机种子和聚合顺序影响结果的计算；
- 会使内存峰值超过安全边界的任务。

并行优化必须证明业务字节、统计结果或允许误差内的数值完全等价。

### 19.3 研究与生产分离

- 研究数据、研究结果、影子信号和正式信号使用不同命名空间；
- 研究代码不能默认写入正式数据；
- 留出集和正式运行凭据采用独立权限；
- 模型晋级通过显式指针或版本切换，不覆盖旧版本；
- 运行异常默认停止新增风险，不自动降级为未经验证的替代模型。

## 二十、推荐研究顺序

### 20.1 总体先后

1. 点时数据、生命周期、公司行动、成分和调整；
2. 特征/标签注册表与可重放研究面板；
3. 成本、组合和事件顺序正确的回测引擎；
4. 第一个窄问题、简单基准和有限参数族；
5. 时间样本外、保管留出和独立复算；
6. 复用第一条路径，登记下一批独立因子或模型命题；
7. 市场状态与行业条件因子；
8. 基本面、估值和事件因子；
9. 期权历史链与独立策略表达研究；
10. 多模型组合、影子运行和条件上线；
11. 更复杂模型、集成和替代数据。

### 20.2 候选研究领域，而非固定队列

研究可从相对领导力、趋势路径、波动结构、成交与流动性、下行脆弱性、市场/行业状态、基本面、估值、财报/事件、跨资产或期权中提出命题。这些是可扩展的来源领域，不是承诺依次开发的模型。

每轮先根据数据准入、经济机制、与现有因子的非冗余性和可证伪性，登记一个有限因子批次；再由开发证据决定是否存在值得构建的模型。模型通过后才设计独立的策略表达。没有因子或模型通过也是正式结果，不能临时改换标签或成本模型来掩盖失败。

### 20.3 90 日研究循环模板

**第 1–3 周：数据与命题**

- 冻结任务书和反例；
- 完成数据源、点时、许可和质量审查；
- 建立标签与简单对照；
- 形成数据就绪报告。

**第 4–6 周：特征与开发**

- 注册有限核心特征；
- 完成单因子诊断和暴露归因；
- 建立透明基准；
- 只在开发区间做有限选择。

**第 7–9 周：验证与稳健性**

- 锁定参数；
- 执行时间验证、多重检验和对抗性测试；
- 加入成本、容量、组合和压力情景；
- 记录通过或拒绝。

**第 10–12 周：留出与实施审查**

- 满足验证门槛后单次打开留出；
- 独立复算与复现；
- 决定拒绝、延长研究或进入影子；
- 不因留出失败修改原版本。

复杂数据准备可能跨越多个循环。进度以证据门禁衡量，不以日历强制晋级。

## 二十二、停止规则与研究红线

出现以下任一情况应停止晋级：

- 无法证明特征在信号截点前可用；
- 历史池缺少退市、公司行动或成分治理；
- 需要反复查看留出集才能得到可接受结果；
- 只有尖锐参数点有效；
- 结果由单一日期、行业或少数证券贡献；
- 正常成本后优势消失或容量极低；
- 复杂模型无法稳定超越简单基准；
- 统计显著但经济价值不足；
- 经济解释与结果方向长期冲突；
- 股票收益被包装为期权收益；
- 价格/成交代理被包装为已证实资金流；
- 数据、代码或结果无法独立复现；
- 为维持结果不断增加未预注册例外。

停止不是失败管理，而是研究质量管理。

## 二十三、最终行动基线

### 23.1 当前应执行的顺序

1. 建成可重放的点时数据底座，并以 3–5 年作为日频研究的优先目标；
2. 建立特征、标签、实验、模型和失败研究登记册；
3. 完成成本与事件顺序正确的股票回测引擎；
4. 登记第一批有限、点时、 outcome-blind 的因子定义并完成覆盖与冗余诊断；
5. 在读取收益前固定标签、成本、因子筛选预算、多重检验与停止规则；
6. 用开发集筛选少量非冗余因子，保留全部失败和真实试验次数；
7. 以简单基准开始模型构建，再在有限预算内证明更复杂方法的增量；
8. 独立冻结策略表达的入场、退出、持有、仓位、成本、容量和风险规则；
9. 锁定因子—模型—表达谱系后进行验证与单次留出，再进入影子运行；
10. 从第一条完整三层路径提炼通用实验、数据、标签、评估与失败登记接口；
11. 以少量分工明确的 Agent 试运行研究工厂，并先评价去重、复现和淘汰质量；
12. 根据证据与数据准入扩展新的研究领域，不预设模型名称或固定数量；
13. 将市场与跨资产状态作为显式因子、条件或风险层逐步加入；
14. 取得高质量期权历史链后，独立研究 DTE、moneyness、价差和 Covered Call；
15. 只有在简单方法样本外不足且数据充分时，升级复杂机器学习；
16. 用持续监控、归因和退役制度保护真实运行。

### 23.2 不变的判断标准

任何新数据、因子、模型或功能都应回答五个问题：

1. 减少了哪一种不确定性？
2. 是否在当时真实可用？
3. 相比明确基准增加了什么？
4. 成本、容量和尾部风险后还剩多少？
5. 在什么情况下必须停止相信它？

无法回答时，不进入下一阶段。

## 附录 A：核心统计定义

```text
Information Coefficient (IC)
    = Corr(prediction_t, future_return_t)

Rank IC
    = SpearmanCorr(rank(prediction_t), rank(future_return_t))

Turnover_t
    = 0.5 × Σ_i |weight_i,t - weight_i,t-1|

Sharpe
    = AnnualizedMean(NetReturn) / AnnualizedVolatility(NetReturn)

Maximum Drawdown
    = min_t (Equity_t / prior_peak_t - 1)

Hit Rate
    = PositiveOutcomeCount / AvailableOutcomeCount

BreakEvenCost
    = Cost level where expected net edge becomes zero
```

IC、Sharpe 和命中率必须配合置信区间、时间稳定性、集中度与成本解释，不能单独作为上线依据。

## 附录 C：版本变更规则

- 文字澄清且不改变研究行为：补丁版本；
- 特征、标签、参数族、成本或统计门槛改变：新研究版本；
- 数据语义、点时规则、公司行动或执行逻辑改变：新数据/引擎版本并重跑受影响研究；
- 留出集已打开后发生任何模型改变：必须建立新研究版本和新的未触碰留出；
- 已上线模型改变：先进入影子或 challenger，不直接覆盖 active 版本。

**行动框架结论：** 专业量化研究不是持续寻找更复杂公式，而是持续减少数据、推断、执行和治理中的不确定性。只有在点时正确、样本外稳健、成本后有效、风险可承受、结果可复现且失效可管理时，研究才具备实际交易价值。
